# App-Symbol „EinsatzSpur“

Entschieden am 28.10.2026: Name **EinsatzSpur**, Symbol Entwurf A (Pfote, deren Ballen ein Standort-Pin ist).
Das Symbol ist für alle Staffeln gleich. Das Logo der Heimatstaffel erscheint nur in der App auf der Startseite.

| Datei | Zweck |
|---|---|
| `symbol.svg` | Vorlage, 1024 × 1024, volle Fläche ohne abgerundete Ecken |
| `symbol-einfarbig.svg` | einfarbige Form ohne Hintergrund |
| `ios/AppIcon.appiconset/` | fertig für `Assets.xcassets` (eine Größe 1024 px, RGB ohne Transparenz) |
| `android/ic_launcher_foreground.xml` | nach `res/drawable/` |
| `android/ic_launcher_monochrome.xml` | nach `res/drawable/` (Designfarben ab Android 13) |
| `android/ic_launcher_background.xml` | nach `res/values/` |
| `android/ic_launcher.xml` | nach `res/mipmap-anydpi-v26/` (auch als `ic_launcher_round.xml`) |
| `android/play-store-512.png` | Symbol für den Play Store |

Farben: Hintergrund `#1D2A3A`, Motiv `#F07A2A`.
